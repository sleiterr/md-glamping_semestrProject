## 🔑 Key Directories Explained

### `/lib` - Backend API
- **Entry Point**: `index.js` loads environment and starts server
- **Server Config**: `server.js` defines Express app and routes
- **Database**: MongoDB schemas and seed data in `/db`
- **Handlers**: Business logic separated from routes
- **Routes**: RESTful API endpoints organized by resource

### `/sites/www/src` - Frontend Application
- **Pages**: Each route has a dedicated page component
- **Components**: Reusable UI components (Header, Button, Forms, etc.)
- **Utils**: Helper functions and API configuration
- **Assets**: Images, fonts, and icons used throughout app

## 🚀 Key Files

| File | Purpose |
|------|---------|
| `index.js` | Backend entry point, loads `.env.local` |
| `lib/server.js` | Express server configuration and route registration |
| `sites/www/src/App.jsx` | Main React component with routing |
| `sites/www/src/pages/LoginPage/LoginPage.jsx` | Authentication page |
| `sites/www/src/components/ProtectedRoute/ProtectedRoute.jsx` | Route guard for admin access |
| `lib/db/models/*.mjs` | Database schemas |
| `lib/routes/auth/auth.js` | Authentication API endpoints |
| `.env.local` | Backend configuration (both root and frontend) |

## 📦 Dependencies

### Backend (package.json @ root)
- express, body-parser, cors
- mongoose (MongoDB)
- jsonwebtoken, bcryptjs (Security)
- multer (File uploads)
- dotenv (Environment)

### Frontend (package.json @ sites/www)
- react, react-router-dom
- vite (Build tool)
- tailwindcss (Styling)
- formik, yup (Form validation)
- react-toastify (Notifications)
- jwt-decode (Token parsing)
